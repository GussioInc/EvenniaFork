Unimplemented Features:
- Skill Proficiency: A system for checking skill proficiency is needed for
  many of the implemented skills to function correctly.
- Positional Combat: Skills like Backstab and Circle Around need a system
  for determining a character's position relative to their target.
- Stun/Status Effects: A more robust system for handling stuns and other
  status effects is needed for skills like Bash and Kick Dirt.
- Exit Interactions: Skills like Bashdoor and Push need a system for
  interacting with exits.

Design Questions:
- Cooldowns: Many skills have cooldowns that are based on rounds rather than
  seconds. The current cooldown system may need to be modified to support this.
